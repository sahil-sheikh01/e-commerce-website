# E-Commerce Website

A full-stack eCommerce website built with **MERN stack (MongoDB, Express.js, React, and Node.js)**. The project provides a complete online shopping experience, including product browsing, filtering, sorting, cart management, product variants, order placement, and online payments.

### Features

* 🛍️ Browse and explore products
* 🔍 Filter and sort products
* 📏 Select product variants such as size
* 🛒 Add products to cart and manage cart items
* 👤 User authentication and account management
* 📦 Place orders with delivery address
* 💵 Cash on Delivery payment option
* 💳 Online payments using **Stripe** and **Razorpay**
* 🛠️ Admin dashboard for managing products and orders
* ➕ Add/upload new products
* 🗑️ Delete products
* 📋 View and manage store products and orders
* 🗄️ MongoDB database for storing users, products, and order data
* 🌐 Backend REST APIs built with Node.js and Express.js
* 🚀 Deployed online using Vercel

### Tech Stack

**Frontend:** React, Tailwind CSS, JavaScript
**Backend:** Node.js, Express.js
**Database:** MongoDB
**Payments:** Stripe, Razorpay
**Deployment:** Vercel

This project demonstrates the development and deployment of a complete MERN-stack eCommerce application with user, product, cart, order, payment, and admin management functionality.
